WB AI Analytics - Инструкция по запуску
============================================

Этот проект позволяет анализировать продажи на Wildberries через удобный дашборд.

ШАГ 1: Установка Python
-------------------------
Убедитесь, что у вас установлен Python 3.9 или выше.
Скачать можно тут: https://www.python.org/downloads/

ШАГ 2: Запуск
---------------
Для Windows:
- Просто дважды кликните по файлу `start.bat`

Для Mac или Linux:
- Откройте терминал в папке проекта
- Выполните команду: bash start.sh

ШАГ 3: Настройка
-----------------
1. После запуска откроется окно "WB AI Launcher".
2. Перейдите на вкладку "⚙️ Настройки".
3. Вставьте туда содержимое JSON-ключа Google (вкладка "Подключение данных").
4. Вставьте ссылку на вашу Google Таблицу.
5. Нажмите "💾 Сохранить и проверить". Должно появиться сообщение "Успех!".

ШАГ 4: Запуск дашборда
-------------------------
1. Перейдите на вкладку "▶️ Запуск".
2. Нажмите кнопку "▶️ Запустить дашборд".
3. Через пару секунд нажмите "🖥️ Открыть дашборд в браузере".

Готово! Теперь вы видите графики и аналитику.

Примечание: Не закрывайте черное окно (терминал) во время работы.
Чтобы остановить: нажмите Ctrl+C в черном окне или просто закройте его.
